# 👾 Invasión Aliens

Proyecto básico desarrollado en **Java** como parte de mi ruta de aprendizaje en programación orientada a objetos (POO).

## 📋 Descripción del Programa
Este programa simula una pequeña invasión espacial en la consola. Su objetivo es poner en práctica la interacción entre múltiples clases, el uso de constructores y la gestión de estados de objetos en memoria.

## 🛠️ Componentes del Código

* [`Alien.java`](./Alien.java): Define la clase plantilla para los enemigos. Controla propiedades como los puntos de vida (`hp`), la especie y el método `recibirDaño()`.
* [`MainAliens.java`](./MainAliens.java): Contiene el método `main`. Inicializa el bucle del juego, genera una oleada de objetos `Alien` y gestiona los turnos de ataque por consola.

## 🚀 Conceptos Aprendidos / Practicados
* Instanciación de objetos en arrays.
* Encapsulamiento (uso de `private`, `getters` y `setters`).
* Estructuras de control condicionales para determinar si un alien sigue vivo.
